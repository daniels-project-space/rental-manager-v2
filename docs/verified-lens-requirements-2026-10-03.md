# Verified lens recommendation requirements

A deployed query for a wide-angle autofocus Sony E lens returned six mount/stock candidates, including a 70–200mm lens and the manual-focus TTArtisan fisheye. Availability was verified, but the requested technical properties were not checked. Baseline: `/root/rental-lens-requirements-baseline.json`.

The real Mastra tool and its Native query now accept structured lens requirements: focus, wide-angle, macro, projection and exclusions, full-frame coverage, focal length/range and separate maximum f-stop or T-stop. The Native reader requires exact reviewed spec identity plus matching capability model, source and a current review timestamp. Missing properties cannot satisfy a requirement. Duplicate spec records require review. Native mount, current-basket stock, ownership, account pricing and rental-stage checks remain in place.

Common explicit descriptors from the query and latest renter message are preserved even when the caller omits structured fields. Negated optional preferences do not become opposite requirements; excluded fisheye/anamorphic choices remain exclusions. Contradictions return no verified matches. The response includes checked requirements, capability evidence and guidance about crop-dependent angle of view and distinct f-stops/T-stops. Natural-language extraction is deliberately limited to those common descriptors; other numeric/technical requirements must be passed explicitly. This is not exhaustive interpretation of every compound request.

Six partial profiles are stored from already reviewed exact models. The [Sony 90mm specification/features page](https://www.sony.co.uk/electronics/camera-lenses/sel90m28g/specifications) additionally establishes autofocus and auto/manual selection. TTArtisan has reviewed manual-focus/fisheye data; the original Remus profiles have reviewed focal lengths, anamorphic projection, coverage and T-stops. Missing focus/wide-angle properties stay unknown. Unconfirmed Sony GM generations are not assigned guessed profiles.

Validation: 18 focused tests across lens requirements, camera requirements and tool scope passed. The five lens tests passed after the final exclusions/AF-alias changes. Final Convex typecheck/deployment and Graphify update passed. Seven actual deployed Native cases passed: baseline refusal, available autofocus macro, exact 100mm anamorphic/T-stop, f-stop refusal, omitted caller properties bound to current renter, a newer manual-fisheye request replacing previous requirements, and conflicting caller focus refusal. The isolated booking stayed unchanged and was cleaned. A final read-only AF-alias query returned the Sony 90mm. Receipts: `/root/rental-lens-requirements-native-proof.json` and `/root/rental-lens-af-supplement.json`. No paid model calls, full-suite or local Next build were used.

The full audit remains active. Capability checks still need enforcement in booking-edit and draft-claim paths when a model bypasses recommendations. Additional model profiles, numeric request binding, subject-specific compound requests, adapter behavior, owner authentication and physical phone acceptance remain open. Real Hygglo activation and writes require separate written consent.
