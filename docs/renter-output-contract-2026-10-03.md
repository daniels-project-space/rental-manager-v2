# Validate the model decision at the route boundary

The canonical draft route decoded JSON and cast it to RenterBotOutput without checking the declared schema, on both the first attempt and grounded retry. A plain prose fallback also returned needs_human=false without a decision envelope. Its comment claimed an empty factsClaimed array activated stricter checking, but the action did not use that array to establish grounding. Model diagnostic claims are never independent evidence.

The agent and both route paths now share one pure output schema and parser. Boolean, string, intent, stage, flag and claim fields must have their declared types, and an answer decision needs nonempty text. A valid human handoff is retained. Plain prose, incomplete JSON and malformed decisions return the bounded invalid_model_output failure code, with no raw model output serialized. The caller saves a persistent critical review when no Native amendment can be recovered. Ordinary regeneration stays held until an explicit review retry. Existing committed-amendment recovery uses the Native ledger, without rerunning the edit or model, and retains stale-message/epoch/context gates.

The model claim taxonomy now distinguishes technical_spec, catalogue_match and quote_readiness from physical availability and kit inclusion. These remain diagnostic self-reports. This change does not establish semantic truth or completeness of every technical claim, and does not make the bot production-ready by itself.

Verification: 50 focused tests across output parsing, reply review and review records; project/backend typechecks. Two controlled registered-action probes used deployed Native lab queries/mutations. A malformed-output failure with no edit saved review, withheld approval, preserved the order and did not regenerate on ordinary retry. A malformed-output failure after one committed date extension recovered the correct £170 confirmation, saved approval, passed send dry-run, and did not repeat the change. Both owned probes were cleaned. Zero new model calls and no real rental writes/sends. Production rollout and exact alias verification recorded separately.
