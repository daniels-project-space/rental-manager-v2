# Booked-period availability and provider state recovery

Availability ends at the agreed rental return window (including the existing 60-minute return handover buffer). A stale delivered/ongoing status does not extend the forecast indefinitely. Physical return, condition inspection and financial settlement remain independent; this change does not release a deposit, cancel an authorisation, close a case or record a return merely because dates elapsed. Repair claims, owner blackouts, vacations and other overlapping allocations retain their separate stock blocks.

Hygglo's active step is the next action. `RETURNED` therefore still occupies its booked period; `REVIEWED` means the return is complete. When a completed funnel has no active step, explicit successful completed `RETURNED` is accepted as terminal return evidence.

The existing top-of-hour full poll also checks a bounded rotating batch of stored delivered/awaiting-return records missing from Hygglo's 50-row list buckets. The protected indexed query examines at most 64 recent rows per account/step (128 total); it selects eight per step, rotating hourly. The poll makes at most sixteen extra provider detail GETs per account. Quick operational and other quarter-hour runs do not perform this recovery. No new schedule is introduced. Failed reads leave saved state intact, and recovery-only GETs do not fabricate current provider-presence rows. Histories beyond the bounded 64-per-step recovery window require an explicit administrative backfill.

On 8 October 2026, five local confirmed/delivered rentals from June/July were checked directly against authenticated provider details. All five explicitly had completed return steps. Their local states were reconciled through the existing owner-service batch upsert and the storefront stock mirror refreshed: 10 current windows across 108 master inventory records. Live A7 V/24–70, Ninja V and RX3 availability restored; the two-FX3 kit remained blocked for current actual hires and available in a later free period. Repair stock was retained. No provider booking, payment or refund writes were performed.

Remaining source inventory limitation: the catalogue has 74 complete owned mappings, 261 incomplete mappings and 70 not-owned mappings. Unverified kits cannot be advertised as available by guessing their stock. Their component mappings need independent reconciliation; marketing listings continue to collect demand and offer available alternatives.
